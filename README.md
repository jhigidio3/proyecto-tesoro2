# proyecto-tesoro2
## Descripción

Este proyecto fue desarrollado como una actividad colaborativa usando Git y GitHub.  
El objetivo es crear una historia entre dos participantes aplicando conceptos como repositorio, ramas, commits, push, pull y merge.

## Tema elegido

El descubrimiento de un tesoro.

## Participantes

- Participante 1: Introducción e inicio de la historia.
- Participante 2: Desarrollo y final de la historia.

## Herramientas utilizadas

- Git
- GitHub
- Editor de texto

## Flujo de trabajo

1. Se creó un repositorio en GitHub.
2. Cada participante clonó el repositorio.
3. Cada uno creó una rama de trabajo.
4. Se realizaron cambios en el archivo historia.txt.
5. Se hicieron commits con mensajes claros.
6. Se subieron los cambios con push.
7. Se integraron los aportes mediante Pull Request y merge.

## Conclusión

La actividad permitió comprender cómo Git ayuda a controlar los cambios de un proyecto y cómo GitHub facilita el trabajo colaborativo entre varias personas.
